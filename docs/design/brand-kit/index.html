Typeform Original

The design system of this Typeform clone, measured from real Typeform screens (workspace, builder, share, results). It copies Typeform's look: a calm plum-gray interface, one dark action color, colored question-type tags, and a monochrome default form. This kit has no manifesto or mascot because Typeform's app has neither.

01

Logo

Typeform's own mark (a pill beside a rounded square), redrawn as SVG at the user's request: this is a clone. Creator UI only (top bar, favicon); public form pages don't carry it, so respondents can't mistake a clone form for a real Typeform. The README states the project is unofficial and not affiliated with Typeform.

Minimum size 16px. In the workspace top bar Typeform shows only the pill; the account avatar fills the square's place. Builder breadcrumbs use the full mark.

Color

Plum-tinted grays, not neutral gray. One dark action color (Primary). Color appears only in question-type tags and status.

03

Type

One family, like Typeform. Inter stands in for Typeform's licensed TWK Lausanne. Regular (400) for titles, Medium (500) for buttons and labels, Semibold (600) for panel headings.

05

Spacing

A 4px scale. Panels sit 16px apart; panel padding is 16–20px; rows are 48px tall with 8px between them.

Radius

06

Motion

Calm and quick. Hover and color changes 150ms ease; menus 180ms; modals 240ms; respondent questions slide 350ms in / 250ms out. All entering motion uses the strong ease-out; exits are ~75% of the entry time. With reduced motion only opacity changes. Keyboard actions never animate in the creator UI.

07

Components

Built only from tokens. These map to the app's own primitives in frontend/components/ui (no shadcn: the app already has its own small set, and shadcn's defaults would pull the look away from Typeform).
