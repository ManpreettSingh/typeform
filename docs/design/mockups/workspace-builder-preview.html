What changes vs. the current app

  • Workspace: Typeform's top bar + rounded light frame, section tabs (Forms active, others "Soon"), left sidebar (Create form, Search, workspace list, totals), and a List view by default with a Grid switch, instead of our card grid only.
  • Builder: Content / Workflow / Connect / Share / Results tabs (Workflow = our logic overview, Connect = integrations placeholder, Share = a full share page like Typeform's); left "Pages" panel with colored type tags; toolbar with Add content, Design, preview; question title, description and choices edited directly on the canvas (like Typeform) instead of text fields in the right panel; right panel keeps only answer type and toggles, plus a Logic card.
  • Default form look: Typeform's current default is monochrome (canvas #FAFAFA, text and buttons #2A222B) with a small square question-number badge, not the old blue "1 →".
  • Colors everywhere: our neutral grays become Typeform's plum-grays; question-type chip colors follow Typeform's groups (text = blue, choice = lavender, rating = green, contact = pink, other = yellow).
  • Kept from our app: dark-mode switch (bonus), "Soon" placeholders instead of Typeform's paid upsells ("View plans", AI chat are left out).
