# Agent Rules

1. Implement **only the phase you are given**. Don't start the next phase or add unrequested features.
2. Before coding: read `ARCHITECTURE.md`, the phase file, and any doc it references. Then state a short plan.
3. Follow the folder layout and naming in `ARCHITECTURE.md`. Don't rename or restructure without asking.
4. Types first: backend Pydantic schemas ↔ `frontend/lib/types.ts` must match `API_SPEC.md`.
5. No hardcoded colors/sizes — use design tokens.
6. Run it: backend starts, frontend builds (`npm run build`), type-check passes. Report anything not verified.
7. Finish by (a) walking through the phase's Acceptance Criteria with pass/fail, (b) updating `docs/PROGRESS.md`, (c) listing known issues.
8. Small, readable files; one responsibility each. Comments only where logic isn't obvious.
9. Original code only (assignment forbids copying repos).
